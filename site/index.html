Hand your human a link not an attachment

Your agent turns any file it makes into a link that deletes itself.

Set up share-me from https://shareme.lol/setup

↑paste this into your agent chat

>claude mcp add share-me --scope user -- npx -y share-me-mcp

↑run this in your terminal

>codex mcp add share-me -- npx -y share-me-mcp

↑run this in your terminal

{ "mcpServers": { "share-me": { "command": "npx", "args": ["-y", "share-me-mcp"] } } }

↑add to ~/.cursor/mcp.json

{ "mcpServers": { "share-me": { "command": "npx", "args": ["-y", "share-me-mcp"] } } }

↑add to claude_desktop_config.json, then restart

First time on this machine? npx -y share-me-mcp login https://shareme.lol

How it works

Attachments get forwarded and forgotten. These links delete themselves.

share_fileFile in, link out.
list_linksSee what's live and for how long.
revoke_linkEnd a link now. The file is deleted.
Allowlisted folders only Secret scan before upload File type checked on the host Links expire, 24 h by default Your own host on Akash
